# EnchLib 1.4.1

Release for Minecraft 26.3 focused on cross-mod integration and developer-facing API clarity.

- Added API registration for mod-provided mob category defaults and API accessors to read or update per-world mob assignments.
- Added a developer guide covering enchantment visibility and defaults, runtime caps, table availability and chance, rarity, item selectors, incompatibilities, and mob categories.
- Documented the optional Eldritch Surge bridge and clarified which runtime systems need to consult EnchLib for settings to affect gameplay.
- Preserved existing per-world mob assignments when merging integration-provided defaults.

The Minecraft 26.x JAR matrix is listed in [minecraft-26.3.md](minecraft-26.3.md); its existing files are release 1.4.0. The 1.4.1 build targets Minecraft 26.3.
