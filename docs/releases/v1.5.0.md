# EnchLib 1.5.0

EnchLib now treats the server's selected world as the source of truth for enchantment settings and presets.

- Moved enchantment values and preset files into each world's `config/enchlib/` directory, so separate worlds and servers can use different rules.
- Copies the bundled preset files into the world on first open. Existing global settings are migrated once to the first world opened; later worlds receive their own copies of the bundled defaults.
- Synchronizes enchantment settings, preset data, and mob categories from server to connected EnchLib clients so Mod Menu displays the selected world's values.
- Routes client edits back to the server as requests. The server saves and broadcasts edits only from operators with permission level 2 or higher; rejected requests are replaced with the server's current settings.
- Keeps commands and runtime API lookups on the active world's server-side configuration.

The current build targets Minecraft 26.3. Download [enchlib-mc26.3-1.5.0.jar](../../jar/enchlib-mc26.3-1.5.0.jar). See the [README](../../README.md) for the world config files, migration behavior, permissions, and multiplayer setup.
