# EnchLib 1.2 – Compatibilità Minecraft 26.x

EnchLib 1.2 include build dedicate per Minecraft 26.1, 26.1.1, 26.1.2, 26.2 e 26.3.

## Aggiornamento tecnico

- Build disponibili per Minecraft `26.1`, `26.1.1`, `26.1.2`, `26.2` e `26.3`, ciascuna con la relativa Fabric API e il requisito Java `25`.
- Ogni jar dichiara nel manifest la propria versione Minecraft esatta.
- Toolchain aggiornata a Fabric Loom `1.17.21` e Gradle `9.6.0`.
- Aggiornati i vincoli di versione in `fabric.mod.json` e la documentazione del progetto.
- Verificato il codice sorgente rispetto alle API Fabric rimosse in 26.3: EnchLib non usa quelle API.
