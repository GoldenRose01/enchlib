# EnchLib 1.4.0

## Novità

- Catalogo mob vanilla aggiornato e modificabile in Excel, con conversione in JSON e supporto agli ID namespaced delle altre mod.
- Importazione di `MobCategory.json` e ricaricamento dei dati in gioco con `/plusec-debug reload`.
- Schermata di configurazione YACL accessibile da Mod Menu per modificare le categorie mentre si gioca.
- Macro menu distinti per disponibilità incantesimi, dettagli e categorie dei mob.
- Dettagli modificabili per rarità, probabilità per tavolo, livello massimo, incompatibilità e compatibilità oggetti.
- Supporto API per tavoli di incantamento registrati dalle altre mod, compresa la Advanced Enchanting Table di Eldritch Surge.
- Reset di una voce o di un intero pannello ai valori predefiniti.
- Conservata la compatibilità con il vecchio `MobCategory.config`.
- Jar compilati per Minecraft 26.1, 26.1.1, 26.1.2, 26.2 e 26.3.

Per i file, le Fabric API abbinate e i requisiti vedere la [matrice Minecraft 26.x](minecraft-26.3.md). Il catalogo, il convertitore e le istruzioni sono nella [cartella doc](../../doc/README.md).
