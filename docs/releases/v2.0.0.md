# EnchLib 2.0.0

**EnchLib** is a per-world enchantment configuration library and API for Fabric, designed for players, modpack creators, and mod developers (with full integration for **Eldrich Surge 2.0.0**).

## Key Features
- **Per-World Enchantment Control**: Enable or disable any vanilla or modded enchantment, customize maximum levels (up to 255), and adjust rarities (`common`, `uncommon`, `rare`, `very_rare`).
- **Enchanting Table Rules**: Configure which enchantments can appear in the vanilla Enchanting Table and modded tables (such as Eldrich Surge's Advanced Enchanting Table), including per-table appearance chances.
- **Villager Trades**: Independently toggle whether enchantments can appear on newly generated villager enchanted books and enchanted items.
- **Item & Mob Categories**: Fine-tune which item categories or specific item IDs can receive each enchantment, and manage per-world mob taxonomy categories (`undead`, `arthropods`, `hell`, `void`, `water`, etc.).
- **Incompatibilities**: Define or override mutually exclusive enchantment sets.
- **Gameplay Enhancements**:
  - **Tree Cutting**: Sneak with an axe to fell trees log-by-log (`fell`) or chop the whole tree (`chop`), automatically integrating with Eldrich Surge's *Lumberjack* enchantment.
  - **Axes as Weapons**: Optionally allow axes to take only 1 durability damage on mob hits and receive sword enchantments.
- **Developer API (`EnchantLibAPI`)**: Clean, stable Java/Kotlin API for registering custom enchantments, tables, rarities, incompatibilities, and mob categories.

## What's New in 2.0.0
- **Eldrich Surge 2.0.0 Compatibility**: Verified and aligned with Eldrich Surge 2.0.0's `EnchLibIntegration` and `EnchLibMobCategories` API calls.
- **Performance Optimization**: Added in-memory caching in `GlobalConfigIO` for `AvailableEnch` and `EnchantmentsDetails`, eliminating repeated disk reads and JSON5 parsing during gameplay.
- **Improved Config GUI**: Reorganized Cloth Config into cleaner, divided tabs (`Available`, `Max Levels`, `Rarity`, `Tables`, `Villagers`, `Items`, `Incompatibilities`, `Mobs`, `Gameplay`) and grouped enchantments and mobs by mod namespace.
- **Mod Ecosystem Compatibility**: Verified compatibility with Mod Menu, Cloth Config, YACL v3, Visual Workbench, and XPlus AutoFish.
